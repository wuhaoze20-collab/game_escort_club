# 流程图绘制规范（draw.io）

本目录下所有 `.drawio` 流程图共用这一套规范。**规范即代码**：
配色、字号、形状、圆角、箭头都写死在 `_src/drawio_kit.py` 里，
不允许在单张图里自己另调一套颜色或字号。

## 1. 硬性约束

- 交付格式：`.drawio`（`<mxfile>` → `<diagram>` → `<mxGraphModel>`），
  **不压缩**（直接写 `<mxGraphModel>`，不要 base64）。
- 一个文件可以含多页 `<diagram>`；页名用「序号 + 中文短标题」。
- **全部中文标注**。技术标识（函数名、参数名、状态名、表名、接口路径）
  保留英文原文，不要翻译。
- **不允许自造流程**：每个节点、每个判定、每条箭头方向，
  都必须能在代码里找到依据，并在图里或交付清单里注明依据文件。
- **不写硬编码数据**：出现的统计数字（表数、节点数、模块数、维度、阈值……）
  必须是现查的真实值；查不到或不确定的，就不写数字，只写含义。
- 全项目视觉统一（见第 2、3 节）。

## 2. 统一视觉规范

| kind | 用途 | 填充 / 描边 | 形状 |
|---|---|---|---|
| `start` / `end` | 起止 | `#D5E8D4` / `#82B366` | 椭圆 |
| `process` | 处理步骤 | `#DAE8FC` / `#6C8EBF` | 圆角矩形（arcSize=10） |
| `decision` | 判定分支 | `#FFE6CC` / `#D79B00` | 菱形 |
| `io` | 输入 / 数据源 | `#FFF2CC` / `#D6B656` | 平行四边形 |
| `data` | 数据库 / 存储 | `#F5F5F5` / `#666666` | 圆柱 |
| `external` | 外部服务（大模型 API 等） | `#B0E3E6` / `#0E8088` | 圆角矩形 |
| `error` | 异常 / 空结果分支 | `#F8CECC` / `#B85450` | 圆角矩形 |
| `note` | 说明批注 | `#FFFFFF` / `#999999` | 便签 |
| `label` | 标题 / 纯文字 | 无 | 纯文字 |
| `group` | 分组框 / 泳道底框 | 无填充 / `#B3B3B3` 虚线 | 直角矩形，标题左上 |

- 字体：`Microsoft YaHei`；节点字号 13，连线标签字号 12，页标题 15 加粗。
- 连线：`edgeStyle=orthogonalEdgeStyle`，圆角 1，箭头 `blockThin`，
  `strokeColor=#666666`；虚线（`dashed=1`）只用于「非主链路 / 旁路 / 引用」。
- 节点默认宽 200，高度**不要手填**——传 `h=None` 让 `auto_height()` 按文字算，
  避免文字被框截断。
- 布局用网格对齐（间距 10 的倍数），同层节点 y 对齐、同列节点 x 对齐。

## 3. 怎么生成

```bash
python docs/flowcharts/drawio/_src/gen_XX_<name>.py     # 生成 .drawio
python docs/flowcharts/drawio/_src/validate_drawio.py docs/flowcharts/drawio
```

生成脚本模板：

```python
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from drawio_kit import Page, write_drawio

HERE = os.path.dirname(os.path.abspath(__file__))
OUT = os.path.join(os.path.dirname(HERE), "0X-名字.drawio")

p = Page("页名")
p.label("t", "页标题（含代码依据文件）", 40, 16, 900, 34, bold=True)
p.node("n1", "文本\n第二行", 40, 60, 200, kind="start")   # h 省略 = 自动高度
p.edge("n1", "n2", "标签")
write_drawio(OUT, [p])
```

## 4. 自检（必须做）

`validate_drawio.py` 会实际解析 XML 并检查：

1. 能被 `xml.etree.ElementTree` 解析；
2. 每页 `<mxCell>` 的 `id` 唯一；
3. `parent` / `source` / `target` 指向的 id 真实存在；
4. 没有自环；
5. **没有断头路**：除终点类节点（椭圆 / 圆柱 / 便签 / 纯文字 / 分组框）外，
   每个节点都必须有出边；
6. 顶点文字非空、文字高度估算不超框；
7. 任意两个实心节点没有明显重叠；
8. 文件是 UTF-8 且无乱码（无 `U+FFFD`）。

**必须做到 0 个错误**；警告要逐条读过，确认是误报或修掉。
