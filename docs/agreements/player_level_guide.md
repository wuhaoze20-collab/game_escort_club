# 打手等级与服务说明

## 第一章 打手等级划分

平台打手分为两大类：娱乐陪和技术陪。

### 第一条 娱乐陪

娱乐陪以轻松娱乐为主，适合聊天、放松、休闲对局。娱乐陪没有技术等级划分，服务单价统一。

### 第二条 技术陪

技术陪以技术实力为核心，由低到高分为五个等级：

1. 985：入门级技术陪，适合日常排位、基础上分
2. 211：进阶级技术陪，适合中高段位对局
3. 大专：熟练级技术陪，具备较强 Carry 能力
4. 魔王护：高端技术陪，适合高段位、高强度对局
5. 明星护：顶级技术陪，平台实力天花板，资源紧张需提前预约

## 第二章 标签系统

### 第一条 标签申请

打手可在个人中心申请添加个人标签，例如"温柔"、"话多"、"枪法准"、"国服"等。

### 第二条 标签审核

标签提交后由管理员或客服审核，审核通过后对外展示，审核不通过则不予显示。

### 第三条 标签数量

每位打手最多展示 5 个标签，请选择最能代表自己特点的标签申请。

## 第三章 好评率规则

### 第一条 好评率计算

好评率等于好评订单数除以已评价订单总数。从未被评价过的打手好评率显示为横杠。

### 第二条 默认好评

订单结单后三天内老板未评价的，系统默认记为好评，但默认好评不在近期评价中展示。

### 第三条 投诉与差评

老板在我的订单界面点击投诉，该订单自动记为差评。打手申诉成功后撤销差评，且计算好评率时屏蔽该订单。
